    What we built · verified · have not proven

    Open-source eyes. Our own judgment layer. Honest limits.

    Built

    Existing open source

    • Ultralytics YOLO: detects road users
    • ByteTrack: keeps IDs across frames
    • OpenCV, Streamlit, Plotly, ReportLab

    NearMiss custom logic

    • Trajectory prediction and conflict gates
    • Same-direction following check
    • Multi-signal suspected-collision detector
    • Evidence association and de-duplication
    • Review record and simulated dispatch audit trail
    • Investigation, briefs, Street Lab, run library

    Verified

      Not yet proven

      • Accuracy on real-world footage has not been measured
      • Image pixels only: no calibrated metres, speeds or probabilities
      • No crash-reduction or safety-rating claim
      • Dispatch is simulated; nothing leaves the computer
      • One camera view, short clips

      Proposed next step

      A supervised pilot before any claims.

      1. Permissioned footage from one fixed camera
      2. Compare NearMiss flags with human-labelled events to measure accuracy
      3. Calibrate the camera view so pixels can become metres
